# Security policy

Please do not open a public issue containing credentials, private keys, tokens, personal data, or an exploitable vulnerability. Use GitHub's private vulnerability reporting feature for security reports.

If a secret was committed or shared, remove it from the working tree **and revoke or rotate it immediately**. Deleting a file does not invalidate a credential and does not remove it from existing clones.

Only the current default branch is supported. This is a small independent project, so response times are best-effort.
